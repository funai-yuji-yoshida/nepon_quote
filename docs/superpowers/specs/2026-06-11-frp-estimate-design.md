# FRP見積機能 設計仕様書

## 概要

FRPタンク製品（ポンプアップ槽・便槽・受水槽）の見積作成専用モードを実装する。
現状ソフト（Excel見積書）の形式に合わせた専用UIとPDFを提供する。

**参照資料:**
- `FRP/20260605/Zoho見積　FRPver２YI打ち合わせ20260605.xlsx`
- `FRP/20260605/現状ソフト　FRPタンク＿新・見積書式打ち合わせ20260605.xls`

---

## 実装スコープ

1. 型式選択ウィザード（⓪→①→②→③）＋見積明細3段表示
2. オプション部品選択
3. 送料計算（Excelデータをコードに埋め込み）
4. FRP専用PDF出力
5. 枠外文言・Hz初期値設定画面

---

## 1. CRMフィールド追加（FRPモジュール）

FRPモジュール（`FRP`）の全フィールド一覧（追加済み）。

**追加フィールド:**

| ラベル | API名 | 型 | 選択肢 / 内容 |
|---|---|---|---|
| 種別（①） | `field3` | 選択リスト | ポンプアップ槽 / ポンプアップ槽【槽のみ】/ 簡易水洗専用便槽 / 無臭便槽 / 小型埋設受水槽 / 特殊受水槽 / くみ取り排水槽 / オプション部品 |
| 中分類（②） | `field4` | 選択リスト | 標準（縦型）/ シンプル / ロング / 横型 / 簡易水洗専用便槽 / かさ上げ / 警報盤セット / フロートスイッチセット / 臭突管セット / 仮固定バンド / 片ユニオンスイングチャッキ |
| 型式グループ（③） | `field1` | 1行 | CRK / CRKUF / CRKUFC / TPK-720 / NKU4 / MKU3 等 |
| 図番 | `field` | 1行 | CK01-No01 / CKU13-No25 等 |
| 送料区分 | `field2` | 数値 | 1 / 2 / 3 / 4 / 40 / 44 / 60 / 100 |
| 対応Hz | `Hz` | 選択リスト | 50Hz / 60Hz / 共通 |

**既存フィールド:**

| ラベル | API名 | 型 | FRPでの用途 |
|---|---|---|---|
| FRPリスト名 | `Name` | 1行 | 製品名（検索・表示） |
| 型式 | `itemnum` | 1行 | 見積2段目の型式 |
| 定価 | `price` | 通貨 | 定価単価 |
| A価 | `A` | 通貨 | 仕切単価A |
| B価 | `B` | 通貨 | 仕切単価B |
| ユアサ | `yuasa` | 通貨 | 仕切単価（ユアサ向け） |
| 単位 | `unit` | 選択リスト | 台 / 個 等 |
| 換算重量 | `field10` | 1行 | 送料計算の参考重量 |
| 仕様1〜9 | `spec1`〜`spec9` | 1行 | 補足仕様（PDF補足行） |
| 順番 | `number` | 数値 | 表示順 |

**オプション部品のデータ登録方法:**
- `①種別` = `オプション部品`
- `②中分類` = かさ上げ / 警報盤セット / フロートスイッチセット / 臭突管セット / 仮固定バンド / 片ユニオンスイングチャッキ
- `送料区分` = 混載便なら1〜3、チャーター等なら40/44

## 2. state拡張

既存の `state.frpMode / frpItems / frpAB` を以下の通り拡張する。

```javascript
state.frpHz         = '50Hz';  // ⓪Hz設定（設定画面で変更可）
state.frpItems      = [];      // FRP明細行（製品＋オプション）
state.frpDiscount   = 0;       // 出精値引き（円）
state.frpFooterText = '';      // 枠外文言（設定画面で管理）
state.frpShowZuban  = true;    // 図番印刷ON/OFF
state.frpCache      = null;    // FRPモジュール全件キャッシュ
```

**FRPアイテム構造:**

```javascript
{
  id,                          // 連番ID
  type: 'product' | 'option', // 製品 or オプション部品
  shubetsu,                   // ①種別（CRMから取得）
  chubunrui,                  // ②中分類（CRMから取得）
  kashira,                    // ③型式グループ（CRMから取得）
  hinmei,                     // 見積記載品名（PDF1段目 = ①種別）
  itemnum,                    // 型式（PDF2段目）
  zuban,                      // 図番（PDF3段目、印刷ON/OFFあり）
  qty,                        // 数量
  unit,                       // 単位
  price,                      // 定価単価
  priceA,                     // 仕切単価A
  priceB,                     // 仕切単価B
  soryoKubun,                 // 送料区分（注意文の自動挿入に使用）
  soryoNote,                  // 送料注意文（自動生成後に手動編集可）
  specs,                      // 仕様1〜9（補足行）
}
```

## 3. 型式選択ウィザード

**起動:** FRPコンテナー内の「製品を追加」ボタン押下でモーダル表示

**ステップ構成:**

```
ステップ1: ⓪ Hz選択
  - 50Hz / 60Hz のラジオボタン
  - state.frpHz の値を初期選択
  - [次へ →]

ステップ2: ① 種別選択（スキップ可）
  - ①種別の全選択肢をリスト表示（オプション部品は除外）
  - [← 戻る] [スキップ] [次へ →]

ステップ3: ② 中分類選択（スキップ可）
  - ①種別に応じて絞り込み（以下の対応テーブルに従う）
  - [← 戻る] [スキップ] [次へ →]

ステップ4: ③ 型式グループ選択
  - frpCacheを①②・Hzでフィルタし、③型式グループの一覧を表示
  - [← 戻る] [次へ →]

ステップ5: 型式一覧から選択
  - ③型式グループ・Hzでフィルタした全レコードを一覧表示
  - レコード選択 → addFrpItem()でstate.frpItemsに追加 → モーダルを閉じる
```

**①種別 × ②中分類 対応テーブル（コードに固定）:**

| ①種別 | 表示する②中分類 |
|---|---|
| ポンプアップ槽 | 標準（縦型）/ シンプル / 横型 |
| ポンプアップ槽【槽のみ】 | 標準（縦型）/ シンプル / ロング / 横型 |
| 簡易水洗専用便槽 / 無臭便槽 / 受水槽系 | 表示なし（②はスキップ） |

**FRPキャッシュ取得:**
- FRPモード開始時に `fetchAllRecords('FRP', 'Name')` で全件取得
- `state.frpCache` に保存（モード終了まで再取得しない）

## 4. オプション部品選択

**起動:** FRPコンテナー内の「オプション部品を追加」ボタン

**ステップ構成:**

```
ステップ1: ② 中分類選択（オプション部品の6種）
  - かさ上げ / 警報盤セット / フロートスイッチセット /
    臭突管セット / 仮固定バンド / 片ユニオンスイングチャッキ

ステップ2: 品名一覧から選択
  - ①種別=オプション部品 かつ ②中分類=選択値でfrpCacheをフィルタ
  - レコード選択 → addFrpItem()で追加
```

## 5. 見積明細（FRPコンテナー）

**テーブル構成:**

| 列 | 内容 |
|---|---|
| No | 連番 |
| 品名（3行） | 1段目: hinmei / 2段目: itemnum / 3段目: 【図番:zuban】（ON/OFF） |
| 送料注意文 | soryoKubunから自動生成、手動編集・削除可 |
| 数量 | 数値入力 |
| 単位 | テキスト |
| 定価合計 | price × qty |
| 仕切合計 | priceA or priceB × qty（frpABで切替） |
| 削除 | ✕ボタン |

**フッター:**

| 行 | 内容 |
|---|---|
| 合計 | 定価合計の総計 / 仕切合計の総計 |
| 出精値引き | 入力欄（円）、定価合計から差し引き |
| 御見積金額（税別） | 定価合計 - 出精値引き |

## 8. 設定画面（枠外文言・Hz初期値）

**起動:** FRPモード時の「⚙️設定」ボタン

**設定項目:**

| 項目 | 内容 |
|---|---|
| Hz初期値 | 50Hz / 60Hz ラジオボタン |
| 枠外文言 | テキストエリア（自由編集） |

**保存先:** `localStorage`（キー: `frp_settings_<所課コード>`）

**初期値（デフォルト）:** 現状ソフトExcelの枠外文言をコードにハードコード

```

　ご注文書とあわせてFAX下さいますようお願いいたします。
・OKサイン図面のFAXを頂き次第、製作開始します。
　また当商品は受注製作品のため、OKサイン図面受信後の製品の仕様変更・返品・
　キャンセルはお受けいたしかねます。あらかじめご了承くださいますようお願い
　申し上げます。

----ご発注後の出荷日延期について----
　ご発注後の出荷日延期につきましては、弊社保管スペースの都合により、当初ご
　指定の出荷予定日（または生産完了日）から1か月以内の範囲で承ります。なお、
　この期間内であっても、月を跨ぐ変更となる場合には、保管および調整にかかる

　弊社決算月（3月・6月・9月・12月）に出荷予定の案件につきましては、上記に
　かかわらず、当該月内での出荷完了をお願いしております。そのため、1か月以内
　の延期であっても、決算月を跨ぐ出荷延期はお受けいたしかねます。

----アフターサービスについて----
・納入後の故障や不具合に関する修理対応につきましては、着脱装置が付いていない
```

## 9. FRP専用PDF出力

**新規関数:** `buildFrpPages(pdfData)` を `pdf-generator.js` に追加

**ページ構成:**

```
[ヘッダー]
  見積番号（NO） / 日付
  取引先名（御中 / 様）
  営業所名・住所・TEL・FAX（所課マスタから）
  件名

[基本情報]
  総価格（税別）
  受渡場所 / 納期 / 備考
  有効期限文言

[明細テーブル]
  No | 品名（3行）| 数量 | 単位 | 定価単価 | 定価合計 | 仕切合計
  ※送料注意文は品名欄の下に表示（スパン）

[合計行]
  合計 / 出精値引き / 御見積金額（税別）

[枠外文言]
  state.frpFooterText を末尾に出力
```

**列構成:**

| モード | 列 | 幅 |
|---|---|---|
| 定価のみ | No / 品名 / 数量 / 単位 / 定価単価 / 定価合計 | 6列 |
| 仕切あり | No / 品名 / 数量 / 単位 / 定価単価 / 定価合計 / 仕切単価 / 仕切合計 | 8列 |

**仕切列の表示:** `pdfPriceMode === 'teika'` のとき仕切列を非表示

**図番の印刷:** `state.frpShowZuban === true` のとき3段目に図番を表示

**ページ分割:** pdfmakeの自動改ページに委ねる
