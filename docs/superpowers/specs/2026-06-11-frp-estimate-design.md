# FRP見積機能 設計仕様書

## 概要

FRPタンク製品（ポンプアップ槽・便槽・受水槽）の見積作成専用モードを実装する。
現状ソフト（Excel見積書）の形式に合わせた専用UIとPDFを提供する。

**参照資料:**
- `FRP/20260605/Zoho見積　FRPver２YI打ち合わせ20260605.xlsx`
- `FRP/20260605/現状ソフト　FRPタンク＿新・見積書式打ち合わせ20260605.xls`

---

## 実装スコープ

1. 型式選択ウィザード（⓪→①→②→③）＋見積明細3段表示
2. オプション部品選択
3. 送料計算（Excelデータをコードに埋め込み）
4. FRP専用PDF出力
5. 枠外文言・Hz初期値 設定画面

---

## 1. CRMフィールド追加（FRPモジュール）

既存FRPモジュール（`FRP`）に以下6フィールドを追加する。

| フィールド名 | 型 | 選択肢 / 内容 |
|---|---|---|
| ①種別 | ピックリスト | ポンプアップ槽 / ポンプアップ槽【槽のみ】/ 簡易水洗専用便槽 / 無臭便槽 / 小型埋設受水槽 / 特殊受水槽 / くみ取り排水槽 / オプション部品 |
| ②中分類 | ピックリスト | 標準（縦型）/ シンプル / ロング / 横型 / 簡易水洗専用便槽 / かさ上げ / 警報盤セット / フロートスイッチセット / 臭突管セット / 仮固定バンド / 片ユニオンスイングチャッキ |
| ③型式グループ | 1行テキスト | CRK / CRKUF / CRKUFC / TPK-720 / NKU4 / MKU3 等（自由入力） |
| 図番 | 1行テキスト | CK01-No01 / CKU13-No25 等 |
| 送料区分 | 数値 | 1 / 2 / 3 / 4 / 40 / 44 / 60 / 100 |
| 対応Hz | ピックリスト | 50Hz / 60Hz / 共通 |

**既存フィールドの使用方法:**

| API名 | ラベル | FRPでの用途 |
|---|---|---|
| `Name` | FRPリスト名 | 製品名（検索・表示） |
| `itemnum` | 型式 | 見積2段目の型式 |
| `price` | 定価 | 定価単価 |
| `A` | A価 | 仕切単価A |
| `B` | B価 | 仕切単価B |
| `unit` | 単位 | 台 / 個 等 |
| `spec1`〜`spec9` | 仕様1〜9 | 補足仕様（PDF補足行） |

**オプション部品のデータ登録方法:**
- `①種別` = `オプション部品`
- `②中分類` = かさ上げ / 警報盤セット / フロートスイッチセット / 臭突管セット / 仮固定バンド / 片ユニオンスイングチャッキ
- `送料区分` = 混載便なら1〜3、チャーター等なら40/44

## 2. state拡張

既存の `state.frpMode / frpItems / frpAB` を以下の通り拡張する。

```javascript
state.frpHz         = '50Hz';  // ⓪Hz設定（設定画面で変更可）
state.frpItems      = [];      // FRP明細行（製品＋オプション）
state.frpDiscount   = 0;       // 出精値引き（円）
state.frpFooterText = '';      // 枠外文言（設定画面で管理）
state.frpShowZuban  = true;    // 図番印刷ON/OFF
state.frpCache      = null;    // FRPモジュール全件キャッシュ
```

**FRPアイテム構造:**

```javascript
{
  id,                          // 連番ID
  type: 'product' | 'option', // 製品 or オプション部品
  shubetsu,                   // ①種別（CRMから取得）
  chubunrui,                  // ②中分類（CRMから取得）
  kashira,                    // ③型式グループ（CRMから取得）
  hinmei,                     // 見積記載品名（PDF1段目 = ①種別）
  itemnum,                    // 型式（PDF2段目）
  zuban,                      // 図番（PDF3段目、印刷ON/OFFあり）
  qty,                        // 数量
  unit,                       // 単位
  price,                      // 定価単価
  priceA,                     // 仕切単価A
  priceB,                     // 仕切単価B
  soryoKubun,                 // 送料区分（注意文の自動挿入に使用）
  soryoNote,                  // 送料注意文（自動生成後に手動編集可）
  specs,                      // 仕様1〜9（補足行）
}
```

## 3. 型式選択ウィザード

**起動:** FRPコンテナ内の「製品を追加」ボタン押下でモーダル表示

**ステップ構成:**

```
ステップ1: ⓪ Hz選択
  - 50Hz / 60Hz のラジオボタン
  - state.frpHz の値を初期選択
  - [次へ →]

ステップ2: ① 種別選択（スキップ可）
  - ①種別の全選択肢をリスト表示（オプション部品は除外）
  - [← 戻る] [スキップ] [次へ →]

ステップ3: ② 中分類選択（スキップ可）
  - ①種別に応じて絞り込み（以下の対応テーブルに従う）
  - [← 戻る] [スキップ] [次へ →]

ステップ4: ③ 型式グループ選択
  - frpCacheを①②・Hzでフィルタし、③型式グループの一覧を表示
  - [← 戻る] [次へ →]

ステップ5: 型式一覧から選択
  - ③型式グループ・Hzでフィルタした全レコードを一覧表示
  - レコード選択 → addFrpItem()でstate.frpItemsに追加 → モーダルを閉じる
```

**①種別 × ②中分類 対応テーブル（コードに固定）:**

| ①種別 | 表示する②中分類 |
|---|---|
| ポンプアップ槽 | 標準（縦型）/ シンプル / 横型 |
| ポンプアップ槽【槽のみ】 | 標準（縦型）/ シンプル / ロング / 横型 |
| 簡易水洗専用便槽 / 無臭便槽 / 受水槽系 | 表示なし（②はスキップ） |

**FRPキャッシュ取得:**
- FRPモード開始時に `fetchAllRecords('FRP', 'Name')` で全件取得
- `state.frpCache` に保存（モード終了まで再取得しない）

## 4. オプション部品選択

**起動:** FRPコンテナ内の「オプション部品を追加」ボタン

**ステップ構成:**

```
ステップ1: ② 中分類選択（オプション部品の6種）
  - かさ上げ / 警報盤セット / フロートスイッチセット /
    臭突管セット / 仮固定バンド / 片ユニオンスイングチャッキ

ステップ2: 品名一覧から選択
  - ①種別=オプション部品 かつ ②中分類=選択値でfrpCacheをフィルタ
  - レコード選択 → addFrpItem()で追加
```

## 5. 見積明細（FRPコンテナ）

**テーブル構成:**

| 列 | 内容 |
|---|---|
| No | 連番 |
| 品名（3行） | 1段目: hinmei / 2段目: itemnum / 3段目: 【図番:zuban】（ON/OFF） |
| 送料注意文 | soryoKubunから自動生成、手動編集・削除可 |
| 数量 | 数値入力 |
| 単位 | テキスト |
| 定価合計 | price × qty |
| 仕切合計 | priceA or priceB × qty（frpABで切替） |
| 削除 | ✕ボタン |

**フッター:**

| 行 | 内容 |
|---|---|
| 合計 | 定価合計の総計 / 仕切合計の総計 |
| 出精値引き | 入力欄（円）、定価合計から差し引き |
| 御見積金額（税別） | 定価合計 - 出精値引き |

## 6. 送料注意文の自動生成ルール

**製品の送料区分（soryoKubun）→ 注意文:**

| 送料区分 | 配送方法 | 注意文 |
|---|---|---|
| 1 / 2 / 3 | 混載便 | （注意文なし） |
| 4 | 4tユニック（現場直送可） | （注意文なし） |
| 40 | 4tユニック（混載切替不可） | ※現場直送不可　現場直送希望の場合は別途チャーター便手配が必要となります |
| 44 | 4tユニック（混載切替可） | ※現場直送不可　現場直送希望の場合は別途チャーター便手配が必要となります（混載便への切替可） |
| 60 | 6tユニック | ※別途チャーター便手配が必要となります |
| 100 | 10t平車 | ※別途チャーター便手配が必要となります |

**オプション部品の送料フラグ → 注意文:**

| フラグ | 注意文 |
|---|---|
| 混載便 | （注意文なし） |
| チャーター等 | ※現場直送不可　現場直送希望の場合は別途チャーター便手配が必要となります |

## 7. 送料金額テーブル（コード埋め込み）

混載便は固定金額。チャーター便（4t/6t/10t）は所課・地域別。
数値は `FRP/20260605/現状ソフト` の各送料シートから移植。

```javascript
const FRP_SORYO_KONZAI = {
  1: 11000,   // 混載便 区分1
  2: 17000,   // 混載便 区分2
  3: 22000,   // 混載便 区分3
};

// チャーター便は所課コード → 地域 → 車種 → 金額
const FRP_SORYO_CHARTER = {
  '28': { // さいたま営業所
    // 送料シートから移植
  },
  // 他の所課...
};
```

## 8. 設定画面（枠外文言・Hz初期値）

**設定項目:**

| 項目 | 内容 |
|---|---|
| Hz初期値 | 50Hz / 60Hz ラジオボタン |
| 枠外文言 | テキストエリア（自由編集） |

## 9. FRP専用PDF出力

**新規関数:** `buildFrpPages(pdfData)` を `pdf-generator.js` に追加

**ページ構成:**

```
[ヘッダー]
  見積番号（NO） / 日付
  取引先名（御中 / 様）
  営業所名・住所・TEL・FAX（所課マスタから）
  件名

[基本情報]
  総価格（税別）
  受渡場所 / 納期 / 備考
  有効期限文言

[明細テーブル]
  No | 品名（3行）| 数量 | 単位 | 定価単価 | 定価合計 | 仕切合計
  ※送料注意文は品名欄の下に表示（スパン）

[合計行]
  合計 / 出精値引き / 御見積金額（税別）

[枠外文言]
  state.frpFooterText を末尾に出力
```

**列構成:**

| モード | 列 | 幅 |
|---|---|---|
| 定価のみ | No / 品名 / 数量 / 単位 / 定価単価 / 定価合計 | 6列 |
| 仕切あり | No / 品名 / 数量 / 単位 / 定価単価 / 定価合計 / 仕切単価 / 仕切合計 | 8列 |

**仕切列の表示:** `pdfPriceMode === 'teika'` のとき仕切列を非表示

**図番の印刷:** `state.frpShowZuban === true` のとき3段目に図番を表示

**ページ分割:** pdfmakeの自動改ページに委ねる
