# FRP見積機能 設計書

**日付:** 2026-04-23
**対象:** mitumori001 ウィジェット（既存ネポン見積への追加）

---

## 概要

既存のネポン見積ウィジェット（mitumori001）に、FRP（繊維強化プラスチック）製品の見積機能を追加する。①基本情報エリアの「FRP」ボタンでFRP専用モードに切り替わり、FRPリストモジュールから製品を検索・追加して見積書を作成できる。

---

## 1. モード切り替え

- ①基本情報エリアに **「FRP」ボタン** を追加
- FRPモード時はボタンがアクティブ強調表示
- FRPモード時は既存の `sectionsContainer` を非表示にし、`frpContainer` を表示
- FRPコンテナ内に「通常モードに戻す」ボタンを設置
- モード切り替え時（どちら方向でも）はデータ消去の確認ダイアログを表示
  - 「入力データが消えます。よろしいですか？」

---

## 2. FRP専用入力画面

### ヘッダー
- 右上に **A価 / B価** トグルボタン（見積単位で切り替え）
- 切り替えると全行の仕切単価・仕切合計が即時再計算・表示更新

### 検索・追加エリア
- テキスト入力ボックス（プレースホルダー: 「品名・型式で検索...」）
- 入力に応じて `ZOHO.CRM.API.searchRecord({ Entity: 'FRP', Type: 'word', Query: キーワード })` で検索
- 品名（Name）・型式（itemnum）どちらにキーワードが含まれてもヒット
- 候補リストから選択すると行が追加される

### 明細テーブル列構成

| 列 | 内容 | 備考 |
|---|---|---|
| 番号 | 行番号 | 自動採番 |
| 品名 | 品名 + 型式 | FRPリストのName + 半角スペース + itemnum（例: "FRPポンプ FRP-001"） |
| 数量 | 手入力 | デフォルト1 |
| 単位 | FRPリストのunit | 表示のみ |
| 定価単価 | FRPリストのprice | 表示のみ |
| 定価合計 | 定価単価 × 数量 | 自動計算 |
| 貴社仕切単価 | A価/B価トグルに応じてA or B | 表示のみ |
| 貴社仕切合計 | 仕切単価 × 数量 | 自動計算 |

### 仕様行
- 製品行の直下に仕様1〜9（値があるもののみ）をインデント行として表示
- 仕様行は品名列のみ使用（他列は空白）
- 仕様行はインタラクションなし（読み取り専用表示）

### フッター
- 定価合計・仕切合計の合計値を右下に表示
- 行の削除ボタン（各行右端）

## 3. Stateデータ設計

### stateへの追加フィールド

```javascript
state.frpMode    = false   // FRPモードフラグ
state.frpAB      = 'A'     // 'A' or 'B'（価格モード）
state.frpItems   = []      // FRP行リスト
```

### frpItem構造（1行分）

```javascript
{
  id:      Number,    // 行ID（連番）
  frpId:   String,    // ZohoレコードID（FRPモジュール）
  name:    String,    // 品名（Name）
  itemnum: String,    // 型式（itemnum）
  qty:     Number,    // 数量（デフォルト1、手入力）
  unit:    String,    // 単位（unit）
  price:   Number,    // 定価（price）
  priceA:  Number,    // A価（A）
  priceB:  Number,    // B価（B）
  specs:   String[],  // 仕様1〜9の値（空文字を除外した配列）
}
```

### CRM保存

既存の `JSON` カスタムフィールドに追記する形で保存。既存データとの互換性を保つ。

```javascript
{
  sections:  [...],   // 既存（通常モード時）
  frpMode:   true,
  frpAB:     'A',
  frpItems:  [...]
}
```

ロード時に `frpMode: true` が検出された場合、自動的にFRPモードで復元する。

## 4. PDF設計

### 表紙（見積鏡）

既存フォーマットを使用。セクション集計行の代わりに以下を表示：

```
No.1 | FRP機器一式 | 1 | 式 | （空白） | ¥仕切合計
```

合計金額は仕切合計（A価 or B価選択に応じた値）を使用。

### 明細ページ（FRP専用テーブル）

既存の明細ページフォーマットをベースに、列構成をFRP用に差し替え。

**列幅:** `[22, *, 25, 20, 45, 45, 50, 50]`（合計8列）

| No | 品名 | 数量 | 単位 | 定価単価 | 定価合計 | 仕切単価 | 仕切合計 |
|---|---|---|---|---|---|---|---|

- 「仕切単価」「仕切合計」列のヘッダーに「(A価)」または「(B価)」を注記
- 仕様行は品名列のみ使用・字下げ表示（他列は空白・罫線なし）
- 最終行に合計行（定価合計・仕切合計のみ）

### buildPdfData() への追加

```javascript
frpMode:   state.frpMode,
frpAB:     state.frpAB,
frpItems:  state.frpItems,
```

## 5. ZohoCRM連携

### FRPリストモジュール（API名: FRP）

| フィールド | API名 | 型 |
|---|---|---|
| 品名 | Name | 1行テキスト |
| 型式 | itemnum | 1行テキスト |
| 定価 | price | 通貨 |
| A価 | A | 通貨 |
| B価 | B | 通貨 |
| 単位 | unit | 選択肢 |
| 仕様1〜9 | spec1〜spec9 | 1行テキスト |
| 換算重量 | field10 | 1行テキスト |
| 順番 | number | 数値 |

### 検索API

```javascript
ZOHO.CRM.API.searchRecord({
  Entity: 'FRP',
  Type: 'word',
  Query: キーワード
})
```

## 7. FRPモード時のサマリー表示

- 既存の「見積まとめ」エリアは `updateOutput()` がFRPモード時は frpItems の合計を使用
- 合計金額 = frpItems の仕切合計（A価 or B価に応じた値）の総和
- 定価合計も別途計算・表示する

---

## 8. 対象外（スコープ外）

- 換算重量（field10）は見積・PDFには使用しない
- ユアサ（yuasa）フィールドは使用しない
- FRPモード時の減衰計算・歩工計算は不要
- FRPモード時の値引き機能は対象外（必要なら別フェーズ）
